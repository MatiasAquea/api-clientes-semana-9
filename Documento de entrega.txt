Descripción breve:
Se implementó una API REST con Node.js, Express y PostgreSQL
para administrar clientes mediante operaciones CRUD:
crear, consultar, actualizar y eliminar.

La API fue probada utilizando Postman y contempla el manejo
de errores para clientes inexistentes y correos duplicados.
